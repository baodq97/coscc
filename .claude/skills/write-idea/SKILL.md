# Write an idea

An observation, not a solution. The only optional stage; `rejected` is a real outcome.

## Steps

1. Record what was noticed, when and where, in the originator's words. One observation per idea.
2. Write `idea.md` in the unit's directory. `## What is not known yet` is required.
3. Cut any figure with no source; cite only committed files.

```markdown
# Idea: <title>
Author: <name>.

## What was noticed

## Why it might matter

## What is not known yet
```

The file carries no status: what the app records is the `judgement` of `submit` (`ready` when
it is written, `not-ready` when it is not).

## Done when

A reader can say what was noticed and why it mattered, and that nothing is decided.
