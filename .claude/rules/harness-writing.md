# Writing the harness

- Say what a model does not already know; what is clear or standard gets a few words at most.
- Short, generic, abstract: a principle with its reason, never a log, an incident, a constant, a
  line number or a special case.
- Layers: CLAUDE.md is shape, commands and conventions; a skill is one stage's process,
  standalone, naming no repository path or other skill; a rule is what breaks in its area that
  no test or code shows; a doc serves one kind of task on demand.
- Keep the shape of any line that code parses.
